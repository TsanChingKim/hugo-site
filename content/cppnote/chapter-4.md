## 一、运算符分类总览

C++ 的运算符大致可以分为以下几类：

| 类别 | 包含运算符 |
|------|-----------|
| 算术运算符 | `+` `-` `*` `/` `%` |
| 关系运算符 | `==` `!=` `<` `>` `<=` `>=` |
| 逻辑运算符 | `!` `&&` `\|\|` |
| 位运算符 | `&` `\|` `^` `~` `<<` `>>` |
| 赋值运算符 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `\|=` `^=` |
| 自增自减 | `++` `--` |
| 条件运算符 | `? :` |
| 逗号运算符 | `,` |
| 成员访问运算符 | `.` `->` `::` |
| 指针相关 | `*` `&` `sizeof` `new` `delete` |
| 类型转换 | `static_cast` `dynamic_cast` `const_cast` `reinterpret_cast` `(type)` |
| 其他 | `sizeof` `alignof` `typeid` `noexcept` 等 |

---

## 二、算术运算符

```cpp
int a = 10, b = 3;
a + b;   // 13
a - b;   // 7
a * b;   // 30
a / b;   // 3 （整数除法，结果只保留整数部分）
a % b;   // 1 （取余数）
```

注意：

- **整数除法**会丢弃小数部分，如果想得到浮点结果，至少一个操作数是浮点型：`10 / 3.0` 结果为 `3.33333`。
- `%` 只能用于整数类型，不能用于浮点数。
- **除零**会导致程序崩溃（浮点数除以零会得到 inf 或 NaN）。

---

## 三、关系运算符

用于比较两个值，返回 `bool` 类型（`true` 或 `false`）。

```cpp
int x = 5, y = 10;
x == y;   // false
x != y;   // true
x < y;    // true
x > y;    // false
x <= y;   // true
x >= y;   // false
```

注意：
- `==` 是相等比较，而 `=` 是赋值，二者极易混淆。
- 比较浮点数时，由于精度问题，直接用 `==` 往往不可靠，通常使用差值小于某个极小值来判断。

---

## 四、逻辑运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `!`    | 逻辑非 | `!true` → `false` |
| `&&`   | 逻辑与 | `true && false` → `false` |
| `\|\|` | 逻辑或 | `true \|\| false` → `true` |

特点：

- **短路求值**：`&&` 左侧为 false 时，右侧不再计算；`||` 左侧为 true 时，右侧不再计算。这可以用来避免无效操作：
  ```cpp
  if (ptr != nullptr && ptr->value > 10) { ... }
  ```

---

## 五、位运算符

位运算符直接对整数的二进制位进行操作。

| 运算符 | 含义 | 示例（以 8 位为例） |
|--------|------|----------------------|
| `&`    | 按位与 | `0b1100 & 0b1010` → `0b1000` |
| `\|`   | 按位或 | `0b1100 \| 0b1010` → `0b1110` |
| `^`    | 按位异或 | `0b1100 ^ 0b1010` → `0b0110` |
| `~`    | 按位取反 | `~0b1100` → 全位取反 |
| `<<`   | 左移 | `1 << 3` → `8` |
| `>>`   | 右移 | `16 >> 2` → `4` |

注意：
- 位运算只能用于整型（`int`、`char`、`long` 等）和 `bool`（不推荐）。
- 右移对于有符号负数，结果依赖编译器（算术移位或逻辑移位），C++20 起定义了负数的右移结果（算术移位）。
- 左移可能会溢出，属于未定义行为（例如 `int` 左移超过位数减一）。

---

## 六、赋值运算符

```cpp
int a = 5;
a += 3;    // a = 8，等价于 a = a + 3
a -= 2;    // a = 6
a *= 4;    // a = 24
a /= 6;    // a = 4
a %= 3;    // a = 1
a <<= 2;   // a = 4
a >>= 1;   // a = 2
a &= 0x0F; // 位与赋值
a |= 0x10; // 位或赋值
a ^= 0xFF; // 异或赋值
```

赋值表达式本身也有值，且是右结合的：

```cpp
int a, b, c;
a = b = c = 0;   // 从右到左依次赋值
```

注意：赋值运算符返回左值引用，因此可以连续赋值。

---

## 七、自增和自减运算符

```cpp
int i = 5;
i++;   // 后置自增：i 变为 6，但表达式返回旧值 5
++i;   // 前置自增：i 变为 7，表达式返回新值 7
```

区别：

- 前置 `++i` 先加再用，效率更高（后置需要拷贝旧值）。
- 后置 `i++` 先用在加。
- 在循环中 `for (int i = 0; i < n; ++i)` 两者效果一样，但前置更推荐。

注意：**不要在同一表达式中对同一个变量多次自增/自减**，例如 `i = i++ + ++i;` 是未定义行为（C++11 之前尤其如此，现代 C++ 也有多种规则，但都是未定义）。

---

## 八、条件（三目）运算符

```cpp
条件表达式 ? 值1 : 值2;
```

```cpp
int a = 10, b = 20;
int max = (a > b) ? a : b;   // max = 20
```

特点：

- 三元运算符是右结合的，可以嵌套，但嵌套过多可读性差。
- 两个分支的类型必须可以隐式转换，否则编译错误。

---

## 九、逗号运算符

在 C++ 中，逗号可以分隔表达式，整个表达式的结果是最后一个表达式的值。

```cpp
int a = 0, b = 1, c = 2;
int x = (a++, b++, c++);   // 先执行 a++ 和 b++，然后 c++ 的值作为整个表达式的结果（即 2）
```

注意：

- 逗号运算符优先级**最低**，因此在赋值时必须加括号，否则会变成变量声明列表。
- 在函数参数列表中的逗号只是分隔符，不是逗号运算符。

---

## 十、成员访问运算符

| 运算符 | 用途 | 示例 |
|--------|------|------|
| `.` | 访问结构体/类对象的成员 | `obj.member` |
| `->` | 通过指针访问成员 | `ptr->member` |
| `::` | 作用域解析 | `std::cout`、`MyClass::staticFunc()` |

示例：

```cpp
struct Point { int x, y; };
Point p{1, 2};
Point* ptr = &p;

p.x;        // 1
ptr->y;     // 2
```

注意：
- `->` 等价于 `(*ptr).member`。
- `::` 除了访问命名空间和静态成员，还可以在类外定义成员函数。

---

## 十一、指针与地址运算符

| 运算符 | 含义 |
|--------|------|
| `&`（一元） | 取地址 |
| `*`（一元） | 解引用（获取指针指向的东西） |

```cpp
int value = 42;
int* ptr = &value;   // & 取地址
std::cout << *ptr;   // * 解引用，输出 42
```

注意：
- 不要混淆二元 `&`（按位与）和一元 `&`（取地址），二者根据操作数个数区分。
- 解引用空指针或野指针是未定义行为。

---

## 十二、`sizeof` 运算符

`sizeof` 在编译时计算类型或变量所占内存字节数。

```cpp
sizeof(int);         // 通常是 4
sizeof(double);      // 通常是 8
sizeof(variable);    // 变量占用的字节数
sizeof(ptr);         // 指针本身占用的字节数（如 8 字节在 64 位系统）
```

注意：
- 对数组名 `sizeof(arr)` 返回整个数组大小（元素个数 × 单个元素大小），但对指针 `sizeof(ptr)` 返回指针大小，两者容易混淆。
- `sizeof` 是运算符，不是函数，所以可以不加括号（`sizeof int` 合法，但通常加括号更清晰）。

---

## 十三、类型转换运算符

C++ 有显式和隐式类型转换。

### 隐式转换（自动）

```cpp
int a = 3;
double b = a;   // int → double，安全但可能损失精度（如果 double 换成 int 会截断）
```

### C 风格强制转换

```cpp
int x = (int)3.99;   // 结果为 3
```

### C++ 四种命名转换

```cpp
static_cast<int>(3.99);                    // 常规类型转换
const_cast<int*>(&constVar);               // 去掉 const 属性
dynamic_cast<Derived*>(basePtr);           // 多态向下转换（运行时类型识别）
reinterpret_cast<long>(address);           // 重新解释底层二进制表示
```

推荐优先使用 `static_cast` 而不是 C 风格转换，因为它更安全、意图更明确。

---

## 十四、输入/输出运算符

- 流插入运算符 `<<` 和流提取运算符 `>>`，用于标准 I/O 和文件流。

```cpp
std::cout << "Hello" << 123;
int n;
std::cin >> n;
```

注意：`<<` 同时是左移运算符，但结合不同的上下文由编译器区分（通过重载）。

---

## 十五、运算符优先级

这是最容易出错的地方之一。下面按优先级从高到低列出常用的运算符（不包含全部）：

1. `::`（作用域解析）
2. `()` `[]` `.` `->` `++`（后置）`--`（后置）`dynamic_cast` 等
3. `++`（前置）`--`（前置）`!` `~` `+`（一元）`-`（一元）`*`（解引用）`&`（取地址）`sizeof`
4. `.*` `->*`
5. `*` `/` `%`
6. `+` `-`
7. `<<` `>>`
8. `<` `<=` `>` `>=`
9. `==` `!=`
10. `&`（按位与）
11. `^`（按位异或）
12. `|`（按位或）
13. `&&`
14. `||`
15. `?:`（条件）
16. `=` `+=` 等赋值运算符
17. `,`

**简单记忆法**：  
> 括号最优先，然后是单目，接着算术（乘除加减），移位，关系，相等，按位，逻辑，条件，赋值，逗号。

如果你不确定优先级，**请加括号**，代码可读性和安全性都会提高。

---

## 十六、运算符重载（C++ 特性）

C++ 允许为自定义类型重载运算符，使对象操作更自然。

```cpp
struct Vector2 {
    double x, y;
};

Vector2 operator+(const Vector2& a, const Vector2& b) {
    return {a.x + b.x, a.y + b.y};
}

Vector2 v1{1, 2}, v2{3, 4};
Vector2 v3 = v1 + v2;   // 可读性高
```

注意事项：
- 不能重载 `::`、`.`、`.*`、`?:`、`sizeof`、`typeid` 等。
- 重载不会改变运算符的优先级和结合性。
- 重载 `++` 和 `--` 时，需要区分前置和后置（后置增加一个 `int` 占位参数）。

---

## 十七、常见易错点总结

1. `=` 和 `==` 混淆：`if (x = 5)` 会把 5 赋给 x，且条件恒为 true。
2. 整数除法 `1/2` 结果为 0，想要 0.5 需要写 `1.0/2`。
3. 浮点数不要直接 `==` 比较。
4. 逻辑或 `||` 写成按位或 `|` 可能导致错误逻辑。
5. 逗号表达式与函数参数混用，少用逗号运算符。
6. 自增多次在同一表达式中使用是未定义行为。
7. `sizeof` 对数组和指针的结果容易搞错。
8. 位运算优先级低于 `==`，例如 `if (x & 0xFF == 0)` 实际被解析为 `x & (0xFF == 0)`，所以位运算建议加括号。

---

## 总结

运算符是 C++ 语言的核心语法之一，掌握好各种运算符的语义、优先级和细节，是写出正确高效代码的前提。建议在编写时多用括号明确运算顺序，避免依赖默认优先级，这样可以减少很多潜在 bug。
