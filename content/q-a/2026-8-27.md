# 隐式this
## 隐式this的使用
```cpp
struct Loader{
	int m_a;
  int m_b;
  void* m_builder;
  bool Initialize(int root, bool verify）;
}

bool Loader::Initialize(int root, bool verify){
	m_a = root;
  m_b = verify ? 1 : 0;
  return true;
}

void CallAll(Loader* x, Loader* y)){
	x->Initialize(7,true);
  y->Initialize(7,true);
}
```
在`Loader::Initialize`中其实省略了`this`关键字，所以该代码等价于：
```cpp
bool Loader::Initialize(int root, bool verify){
	this.m_a = root;
  this.m_b = verify ? 1 : 0;
  return true;
}
```
而这里的`this`指向的是调用它的对象。
`CallAll`函数里的`x->Initialize(7, true)`在调用`Initialize`方法之后的伪代码是：
```cpp
x.m_a = root;
x.m_b = verify ? 1 : 0;
return true;
```
`CallAll`函数里的`y->Initialize(7,true)`在调用`Initialize`方法之后的伪代码是：
```cpp
y.m_a = root;
y.m_b = verify ? 1 : 0;
return true;
```
这就分别给`x`和`y`进行了赋值。
